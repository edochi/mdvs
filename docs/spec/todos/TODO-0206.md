# TODO-0206: Strip symbols from release binaries

## Summary

Neither `[profile.release]` nor `[profile.dist]` strips symbols. Stripping cut
process startup by ~40 ms in a 2026-10-19 measurement, more than the ~30 ms the
Lance 10 upgrade (TODO-0203) added, and shrinks the 242 MB binary.

## Details

- Add `strip = true` (or `"symbols"`) to `[profile.dist]` in the workspace
  `Cargo.toml`, and decide whether `[profile.release]` (used by `cargo install`)
  gets it too.
- Check what is lost: panic backtraces keep function names only with
  `strip = "debuginfo"`; full `strip = true` drops them. Decide which one.
- Re-measure startup and binary size on the K8s docs corpus with
  `docs/benchmarks/run.py` before and after.
