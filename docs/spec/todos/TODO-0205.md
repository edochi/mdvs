# TODO-0205: Revisit the default embedding model's load cost

## Summary

The default model changed from `potion-base-8M` to `potion-multilingual-128M` on
2026-06-23 (`646a7a4`). The new model is ~506 MB and takes ~560 ms to load,
versus ~30 MB and ~20–40 ms. Every semantic or hybrid search pays that load, so
default search on the K8s docs corpus went from ~490 ms to ~1.2 s.

## Details

Measured on 2026-10-19 (K8s docs corpus, 1,669 files, release build): the
installed v0.8.6 with `potion-base-8M` runs a default search in ~490 ms end to
end (~305 ms engine-only), in line with the June benchmark. The same binary with
the current default takes ~1.2 s, almost all of it model load.

This is a product decision, not a bug: multilingual quality versus half a second
on every search. Options:

- Keep the multilingual default and document the cost.
- Go back to `potion-base-8M` (or another small model) as the default, and
  document `potion-multilingual-128M` as the choice for non-English vaults.
- Pick the default at `init` from the corpus language (adds a heuristic).
- Cut the load cost itself (e.g. memory-map the weights, if model2vec-rs allows
  it), so the default doesn't matter as much.

Whatever is chosen, the benchmark report should say which model it measured
(TODO-0207).
