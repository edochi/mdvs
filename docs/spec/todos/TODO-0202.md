# TODO-0202: Merge and group imports with nightly rustfmt

## Summary

Make `use` blocks consistent — one `use` per crate, grouped std / external /
crate — and enforce it in CI. Clippy has no lint for this; it is a rustfmt
concern, and the two options that do it are nightly-only. Lands on
`feat/clippy-pedantic`, in the same PR as TODO-0197.

## Details

Today import style is mixed, e.g. `main.rs`:

```rust
use std::process::ExitCode;
use tracing_subscriber::EnvFilter;
use tracing_subscriber::layer::SubscriberExt;
use tracing_subscriber::util::SubscriberInitExt;
use tracing_tree::HierarchicalLayer;
use tracing_tree::time::Uptime;
```

which the target style writes as

```rust
use std::process::ExitCode;

use tracing_subscriber::{EnvFilter, layer::SubscriberExt, util::SubscriberInitExt};
use tracing_tree::{HierarchicalLayer, time::Uptime};
```

The rustfmt options are `imports_granularity = "Crate"` and
`group_imports = "StdExternalCrate"`. Both are unstable: stable rustfmt (the
pinned `1.97.1` toolchain, and CI's `cargo fmt --check`) ignores them, so a
`rustfmt.toml` alone neither formats nor enforces anything.

Measured 2026-10-05 with `rustfmt 1.8.0-nightly (2026-01-24)`: applying both
options touches 66 files (116 hunks), all import blocks.

Plan — two commits:

1. **Config and tooling** (`chore:`):
   - Add `rustfmt.toml` with the two options.
   - Format with nightly rustfmt only; build, clippy and tests stay on the
     pinned stable toolchain. Add a `just fmt` recipe (and `just fmt-check`)
     wrapping `cargo +nightly fmt` so nobody has to remember the toolchain.
   - CI: install a nightly toolchain with the `rustfmt` component (minimal
     profile) and replace `cargo fmt --check` with the nightly check.
   - Update every place that says `cargo fmt`: `AGENTS.md` (Build & Verify),
     `.claude/skills/agent-contract/SKILL.md` (formatting rule and gate),
     `.claude/skills/code-editing/SKILL.md`, `.claude/skills/release/SKILL.md`,
     `docs/spec/release.md`.
2. **Mechanical reformat** (`style:`): run the new formatter over the workspace,
   commit only that — no other changes — so it reviews as a pure formatting
   diff. `cargo test` and clippy must stay green.

Decision (user, 2026-10-05): **pin** the nightly to a date in one place shared
by CI and the `just` recipes, and bump it deliberately; floating on latest
nightly is rejected because rustfmt changes would cause surprise reformat churn.
The date is chosen at implementation (a recent nightly whose rustfmt supports
both options).
